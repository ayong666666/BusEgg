# 蛋蛋巴士官网与后台管理系统需求文档

## 1. 项目目标

本项目计划从当前静态官网升级为前后端分离系统。

目标包括：

- 使用 Vue 实现官网前端展示。
- 使用 Vue 实现后台管理系统。
- 使用 Spring Boot 提供后端接口。
- 使用 MySQL 存储业务数据。
- 后续部署到腾讯云 Ubuntu 服务器。

当前阶段暂不部署，先完成需求文档和开发文档。

## 2. 协作约定

本项目后续开发过程中，所有代码生成和代码修改都遵循以下规则：

1. 每次生成代码前，先确认需求。
2. 每次修改代码前，先确认修改范围。
3. 未确认前，不直接生成业务代码。
4. 需求确认内容至少包括页面、功能、接口、数据字段和交互规则。
5. 部署到腾讯云服务器前，需要单独确认部署方案、域名、端口、数据库、Nginx 和 HTTPS 配置。
6. 每开发完成一个功能并经确认无问题后，需要同步更新开发文档，记录本次完成内容、涉及文件、接口、数据库变化和后续注意事项。

Spring Boot 3

### 3.4 数据库

```text
MySQL 8
```

### 3.5 数据库命名模板

数据库命名需要根据业务场景区分，统一使用小写字母、数字和下划线。

推荐格式：

```text
项目名_业务场景_环境
```

其中：

```text
项目名：busegg
业务场景：site / admin / mall / miniapp / order / test 等
环境：dev / test / prod
```

示例：

```text
busegg_site_dev       官网与后台第一版开发库
busegg_site_test      官网与后台测试库
busegg_site_prod      官网与后台生产库
busegg_mall_dev       后续商城业务开发库
busegg_miniapp_dev    后续小程序业务开发库
busegg_order_prod     后续订单业务生产库
```

第一版建议使用：

```text
busegg_site_dev
```

生产环境上线前再创建：

```text
busegg_site_prod
```

## 4. 用户角色

### 4.1 官网访客

官网访客可以：

- 浏览官网首页。
- 查看产品与服务。
- 查看社区店解决方案。
- 查看招商合作信息。
- 查看新闻动态。
- 提交合作意向。

### 4.2 普通管理员

普通管理员可以：

- 登录后台。
- 查看工作台数据。
- 查看和处理留资信息。
- 管理产品。
- 管理新闻。
- 上传图片。

### 4.3 超级管理员

超级管理员可以：

- 拥有普通管理员的全部权限。
- 管理管理员账号。
- 管理角色权限。
- 修改官网基础配置。

第一版权限可以简化为：

```text
超级管理员
普通管理员
```

## 5. 官网前端需求

### 5.1 首页

首页需要保留当前静态项目的整体展示结构。

模块包括：

- 顶部导航
- 首页首屏
- 品牌价值
- 产品与服务
- 社区店解决方案
- 招商合作
- 关于我们
- 新闻动态
- 联系我们
- 页脚

### 5.2 顶部导航

导航菜单包括：

- 首页
- 产品介绍
- 解决方案
- 招商合作
- 关于我们
- 新闻动态
- 联系我们

交互要求：

- PC 端横向导航。
- 移动端折叠菜单。
- 点击菜单可跳转到对应区域。
- 滚动页面时导航样式可变化。

### 5.3 产品与服务

展示内容包括：

- 可溯源鲜鸡蛋
- 蛋蛋巴士小程序
- 商家经营后台
- 社区店合作服务

后续产品内容应支持后台维护。

### 5.4 社区店解决方案

展示社区店流量增长方案。

核心内容包括：

- 线上发放权益
- 引导到店领取
- 门店复购运营

### 5.5 招商合作

合作类型包括：

- 社区店合作
- 鸡蛋商合作
- 城市运营合作
- 其他咨询

### 5.6 新闻动态

新闻动态需要支持：

- 新闻列表展示。
- 新闻详情展示。
- 从后台管理系统维护内容。

第一版可以只展示新闻列表，详情页可在第二版补充。

### 5.7 联系我们 / 合作意向表单

表单字段：

```text
姓名
联系电话
合作类型
留言
```

提交后写入 MySQL，由后台管理系统查看和处理。

校验要求：

- 姓名必填。
- 联系电话必填。
- 合作类型必填。
- 手机号格式需要校验。
- 防止重复提交。

## 6. 后台管理系统需求

### 6.1 登录 / 退出

功能：

- 管理员登录。
- 登录成功后保存 JWT。
- 退出登录。
- 登录过期自动跳转登录页。

### 6.2 工作台

展示统计数据：

- 今日留言数
- 待跟进数
- 已合作数
- 产品数量
- 新闻数量

### 6.3 留资管理

功能：

- 留资列表。
- 留资详情。
- 按合作类型筛选。
- 按处理状态筛选。
- 按手机号或姓名搜索。
- 修改处理状态。
- 添加跟进备注。

处理状态：

```text
未处理
跟进中
已合作
无效
```

### 6.4 产品管理

功能：

- 产品列表。
- 新增产品。
- 编辑产品。
- 删除产品。
- 上架 / 下架。
- 排序。
- 上传封面图。

字段：

```text
产品名称
产品分类
产品简介
产品详情
封面图
排序值
状态
```

### 6.5 新闻管理

功能：

- 新闻列表。
- 新增新闻。
- 编辑新闻。
- 删除新闻。
- 发布 / 下线。
- 上传封面图。

字段：

```text
标题
摘要
正文
封面图
发布时间
排序值
状态
```

### 6.6 轮播图管理

功能：

- 轮播图列表。
- 新增轮播图。
- 编辑轮播图。
- 删除轮播图。

- 排序。

字段：

```text
标题
图片
跳转链接
排序值
状态
```

### 6.7 官网配置

可配置内容：

- 公司名称

- 首页副标题

### 6.10 角色权限

## 7. 后端接口需求

接口分为两类：

```text
/api/site/**     官网公开接口
/api/admin/**    后台管理接口
```

### 7.1 官网接口

```text
GET  /api/site/config
GET  /api/site/banners
GET  /api/site/products
GET  /api/site/news
GET  /api/site/news/{id}
POST /api/site/leads
```

### 7.2 后台认证接口

```text
POST /api/admin/auth/login
POST /api/admin/auth/logout
GET  /api/admin/auth/profile
```

### 7.3 后台管理接口

```text
/api/admin/leads
/api/admin/products
/api/admin/news
/api/admin/banners
/api/admin/site-config
/api/admin/files
/api/admin/users
/api/admin/roles
```
